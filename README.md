# Bhavesh Kolhe — React Portfolio

A minimal, editorial-style responsive portfolio built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Create a production build:

```bash
npm run build
npm run preview
```

## Personalise before publishing

1. Replace the two sample entries in `projects` inside `src/main.jsx` with Bhavesh's real projects, descriptions, technologies and links.
2. Update the skills array to reflect his actual skills and proficiency.
3. Replace the LinkedIn and GitHub profile URLs in the contact section with his real profile URLs.
4. Review the About copy and availability status so they accurately represent him.
5. Replace the portrait at `public/bhavesh-portrait.webp` if a different crop is preferred.

## Deploy

Push the project to GitHub and import it into Vercel or Netlify. Use `npm run build` as the build command and `dist` as the output directory.
